# SSH 高级特征采集与观察部署

2026-09-24 已部署到国内 VPS、5090、4090-1、4090-2。现有 SSH 命令、密码认证及 FRP 配置保留。高级指纹评分本身仍只观察；同日后续已在 frp-ssh-guard 接入精确归因的密码失败自动封禁，详见 ../ssh-guard/README.md 的最新规则。下文“观察规则”仅指指纹评分模块，不代表整体防护不封禁。

## 数据链路

- VPS eth0 被动采集 51022–51024，GPU lo 被动采集本地 22 的 SSH 握手。
- dumpcap → 管道 → TShark，仅提取元数据；不持久化原始抓包，不读取密码或 SSH 会话内容。
- 特征：真实来源 IP/端口、目标服务器、起止时间、客户端 banner、HASSH/算法列表、客户端及服务端 KEX 随机 cookie。
- GPU 从 systemd 可信 ssh.service/sshd.service 日志提取成功、失败、无效用户名事件，不上报完整日志。
- 用双方 cookie、对应服务器和时间窗口匹配两端连接，再用本地回环 IP/端口、SYN 与连接生命周期关联认证日志。两个 cookie 必须同时一致，且候选必须唯一；不以时间近似或单独 HASSH 归因。
- 缺包、采集轮换、长握手、未完成握手、时钟偏差、关联歧义均可能导致未关联，不能据此封禁。香港 FRP 和学校直连不在国内 VPS 关联范围内。
- GPU 每台独立令牌，通过有效证书 HTTPS 上报；VPS 接收仅监听 127.0.0.1:28460。Nginx 精确路径 /internal/ssh-features/v1 限流、限制 POST 和 256 KB 请求，未认证请求 403。报告不对公网提供。

## 当前观察规则

窗口 10 分钟：从第 3 次可精确关联的失败开始累计分值（最高 40）；至少 3 个不存在的用户名加 25；至少 4 次失败且跨两台服务器加 20；至少 6 次连接间隔呈固定节奏加 5。仅指纹相同或跨服务器连接不单独触发封禁建议。

- 普通来源：至少 6 次失败且评分 ≥50，建议临时封禁 1 小时。
- 合肥来源：至少 18 次失败且评分 ≥75，建议临时封禁 10 分钟。
- 单次输错和单个无效用户名不加分。
- ≥3 个 IP 使用相同 HASSH、尝试相同用户名且每个 IP ≥2 次实际失败，记录可疑群组，建议群组新连接限速；不据此自动连带封禁。
- 合肥分类复用原防护地理数据，45 天过期后按普通来源。IP 属地不是身份认证。
- 原有 frp-ssh-guard 继续独立执行限速、递进封禁等规则。本模块没有调用 nft/iptables 的代码路径。

## 运行与观察

- 代码 /opt/frp-ssh-features/；配置 /etc/frp-ssh-features/（令牌文件 0600）。
- 数据 /var/lib/frp-ssh-features/events.sqlite；保留 7 天，flow/auth 各最多 200000 行，按小时清理，数据库会复用已释放页。
- 采集端有最多 10000 条持久化队列，网络恢复后重试；超过约 24 小时的记录丢弃并计数，不将陈旧记录用于归因。
- 单次采集 10 分钟后轮换，限制长期协议解析状态；每次最多 10000 条流。轮换瞬间可能漏掉握手，按未关联处理。
- 服务 frp-ssh-features-agent（四台），frp-ssh-features-receiver（VPS），均开机启动/异常自动恢复。
- 每日 01:15（VPS 系统时区）运行 frp-ssh-features-report.timer，生成近 24 小时认证统计、高风险快照及健康报告；文件名按 UTC，保留 8 天。
- 采集服务 CPU 上限 20%、内存上限 384 MB；接收/分析 CPU 上限 20%、内存上限 192 MB。首次稳定验证 VPS 实际合计约 92 MB。

VPS 上运行：

```sh
python3 /opt/frp-ssh-features/receiver.py status
python3 /opt/frp-ssh-features/receiver.py report
journalctl -u frp-ssh-features-agent -u frp-ssh-features-receiver --since today
```

建议积累 3–7 天正常使用样本后复核：四台心跳应持续新鲜（一般 <90 秒），检查队列溢出/过期、采集异常、关联覆盖率、共享出口/VS Code/SFTP 的误报、群组候选证据。具备可靠归因并验证误报可接受后，再实现并启用选择性的自动处置；观察版没有隐藏的定时启用开关。

备份：VPS `/var/backups/ssh-features-20260924/lab-status`。TShark 软件包保留为可复用工具；5090 安装时因原镜像错误，采用临时源配置，没有改动系统软件源。
