实验室独立远程桌面

这里是当前 Linux 账号的独立桌面，文件和权限与 SSH 一致。
网页验证成功即进入，不需要再次登录系统；原有物理桌面不会被接管。
每台服务器同一时间只允许一人通过网页操作。

“断开并保留”会释放远程占用，保留本账号的桌面和窗口。
下次使用相同账号验证后恢复。其他账号进入自己的桌面。
“结束桌面”会关闭本桌面中的应用，未保存内容会丢失。
它不会结束你从 SSH 启动的计算任务，也不注销原有物理桌面。

OpenGL 图形软件：双击“OpenGL GPU 加速启动”选择软件；
也可以在终端输入：lab-opengl 程序名 参数
例如：lab-opengl glxinfo -B
多张 GPU 时可以设置 LAB_OPENGL_DEVICE=egl1 选择另一张卡。

Vulkan / CUDA：直接启动程序，不要套用 lab-opengl。
普通桌面组件使用轻量配置；桌面缩放可使用浏览器窗口或全屏。
不要在此会话使用屏幕锁定；网页访问已通过服务器账号验证。
